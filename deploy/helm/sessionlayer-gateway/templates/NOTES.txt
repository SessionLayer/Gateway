{{- if and (eq .Values.ha.mode "ha") (eq (dig "backend" "in_process" .Values.ha.coordination) "in_process") }}
ha.mode is ha but ha.coordination is in_process, which reaches no other process.
This release is one Gateway, so a second one is a second release, and a session
landing on a Gateway that does not own the node's agent channel has no way to
signal the owner. Set ha.coordination to the nats backend for a fleet serving
agent-based nodes.
{{- end }}
{{- if and (eq .Values.service.type "LoadBalancer") (ne .Values.service.externalTrafficPolicy "Local") (or .Values.config.existingSecret (not .Values.ssh.proxy.lbCidrs)) }}

the load balancer's ranges in ssh.proxy.lbCidrs and have it send PROXY protocol
v2.
